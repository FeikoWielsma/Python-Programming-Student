Exercise 1 : Python Intro

Write a short Python program, change what it displays, and run it again. The aim is to practise working with a file in the editor and seeing the result in the terminal. The wordle folder you create here becomes your game project from Exercise 2 onwards.

Step 1 : Prepare the tools

Install Visual Studio Code from https://code.visualstudio.com/. Open it, select the Extensions icon on the left, search for Python, and install the extension published by Microsoft.

Python is the application that runs your code. The tool uv installs Python and starts it for your project. On Windows, open the Start menu, search for PowerShell and open it. Paste this command and press Enter :

On macOS or Linux, open the Terminal application and use this command instead :

curl -LsSf https://astral.sh/uv/install.sh | sh

Wait for the terminal prompt to return before entering another command. If uv is not recognised, close and reopen the terminal application. The slides Preparing Python and Editor Setup show these installation steps.

def score_guess(secret: str, guess: str) -> list[str]:
    """Mark each letter of guess as "green", "yellow" or "grey".

    A letter is yellow only while the secret still has an unmatched copy of it,
    so one E in the secret cannot make two E's in the guess yellow.
    """
    marks = ["grey"] * WORD_LENGTH
    unmatched: list[str] = []

    # First pass : exact matches. Whatever the secret has left over is
    # available to be found elsewhere.
    for position, letter in enumerate(guess):
        if letter == secret[position]:
            marks[position] = "green"
        else:
            unmatched.append(secret[position])

    # Second pass : right letter, wrong place, each copy used at most once.
    for position, letter in enumerate(guess):
        if marks[position] != "green" and letter in unmatched:
            marks[position] = "yellow"
            unmatched.remove(letter)

    return marks

Step 2 : Say exactly what a mark is

The marks that score_guess returns are declared as list[str]. That is true, but it is also true of ["gray", "blue", "yes"]. The game only has three marks : "green", "yellow" and "grey". A type that lists exactly those can be checked.

def follows_hints(guess: str, history: list[tuple[str, list[Mark]]]) -> bool:
    """Return whether guess keeps green letters and includes yellow ones."""
    for previous, marks in history:
        for position, (letter, mark) in enumerate(zip(previous, marks, strict=True)):
            if mark == "green" and guess[position] != letter:
                return False
            if mark == "yellow" and letter not in guess:

    return True

def save_game(
    secret: str, history: list[tuple[str, list[Mark]]], max_guesses: int, hard: bool
) -> None:
    """Write the secret, the scored guesses and the game's settings to the save file."""
    data = {"secret": secret, "history": history, "max_guesses": max_guesses, "hard": hard}
    SAVE_PATH.write_text(json.dumps(data, indent=2), encoding="utf-8")


def load_saved_game() -> tuple[str, list[tuple[str, list[Mark]]], int, bool] | None:
    """Read a saved game, returning None when no save exists."""
    if not SAVE_PATH.exists():
        return None
    data = json.loads(SAVE_PATH.read_text(encoding="utf-8"))
    history = [(word, marks) for word, marks in data["history"]]
    return data["secret"], history, data["max_guesses"], data["hard"]


def clear_saved_game() -> None:
    """Remove the save after a game is complete."""
    SAVE_PATH.unlink(missing_ok=True)
